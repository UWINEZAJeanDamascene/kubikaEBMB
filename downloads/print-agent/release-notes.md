# Kubika Print Agent 0.1.5

- Adds redacted rotating JSON logs and a protected diagnostics export.
- Reports Windows printer status and surfaces backend agent, printer, failure, and queue alerts.
- Installer upgrade stops the service before replacing files; uninstall prompts to keep or remove shop data.
- Includes the LocalSystem printer visibility comparison script and release SHA-256 verifier.
